MIRA – Menstrual Health & Wellness

MIRA is a cloud-based menstrual health and wellness application designed to support users through cycle tracking, AI-powered health conversations, emotional insights, and personalized notifications. The application integrates Firebase for authentication and cloud data storage, along with AI-powered chatbot functionality to provide accessible and personalized support.

Flutter Dart Firebase Auth & Firestore AI Integration (Gemini) Push Notifications (FCM)
24/7 AI Health Chatbot
Cycle Prediction & Logs
Smart Emotional Analytics
Secure Cloud Privacy & Auth

Project Overview

MIRA was built to solve the lack of personalized, empathetic, and scientifically backed menstrual health guidance in modern mobile apps.

By blending an intuitive Flutter frontend with Firebase cloud infrastructure and an AI conversational agent, MIRA gives women confidential, instant answers and holistic cycle tracking.

Key Features

  • AI-powered health chatbot: Conversational guidance on symptoms, cycle phases, and wellness tips.
  • Personalized notifications: Timely reminders for upcoming phases, fertile windows, and health logs.
  • Emotional prediction dashboard: Tracks mood variations and correlates them with hormonal cycles.
  • Secure privacy management: Encrypted user data backed by Firebase Authentication and cloud rules.

Technologies Used

Crafted with high performance cross-platform mobile architecture:

Flutter Dart Firebase Auth Cloud Firestore Firebase Cloud Messaging (FCM) Gemini AI API State Management

User Privacy & UX

  • End-to-end data encryption for sensitive health logs.
  • Calming pastel design system tailored for wellness mindfulness.
  • Offline symptom journaling with automatic cloud synchronization.
  • Personalized weekly wellness summaries and symptom pattern reports.
