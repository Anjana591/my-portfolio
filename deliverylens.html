DeliveryLens – Food Delivery Time Analytics

DeliveryLens is a comprehensive data analytics and machine learning project that investigates food delivery delays and the factors influencing order transit times. Combining exploratory data analysis, SQL queries, predictive ML models, SHAP explainability, and interactive Power BI dashboards, it transforms delivery logs into actionable operational insights.

Project Overview

DeliveryLens addresses the critical challenge of delivery unpredictability in on-demand food logistics. By conducting thorough exploratory data analysis and building regression & classification models, this project pinpoints why delays occur and predicts exact estimated delivery times (ETA).

The outcome equips fleet managers and operations teams with real-time risk visibility and data-driven recommendations to reduce bottlenecks.

Key Features

  • End-to-end data cleaning and outlier removal for GPS and timestamp features.
  • In-depth SQL queries to aggregate traffic, weather, and peak meal hour patterns.
  • Predictive machine learning model for delivery duration and delay probability.
  • SHAP (SHapley Additive exPlanations) for model transparency and what-if factor evaluation.
  • Interactive Power BI dashboards with drill-downs across delivery zones and rider performance.

Technologies & Pipeline

Utilized an end-to-end modern data science stack:

Python Pandas & NumPy PostgreSQL / MySQL Scikit-Learn XGBoost SHAP Explainability Power BI Desktop DAX Queries

Key Analytical Insights

  • Weather conditions (heavy rain/fog) contributed to an average +12 min delay surge.
  • Rider age and experience directly correlated with delivery speed during peak evening hours.
  • Multiple order pickups from dense cluster hubs reduced overall transit time by 18%.
  • Traffic density was isolated via SHAP as the #1 predictive factor of delay escalation.
